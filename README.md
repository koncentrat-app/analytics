## Направление 1. Индивидуальная разработка BI, данных и ИИ для бизнеса (koncentrat.app/custom)

От сбора данных из любых источников до ИИ-агентов и единой аналитической платформы — 1С, CRM, Битрикс24, маркетплейсы, API. Направление не ограничено маркетплейсами и подходит для любого бизнеса, которому нужна кастомная аналитика.

### Что разрабатывают

- Сбор данных в БД — по API и парсингом (внешний сбор данных)
- Агрегация и подготовка данных — приведение разрозненных источников к единому виду
- Настройка ИТ-инфраструктуры — серверы, хранилища, каналы выгрузки
- Создание единой платформы — объединение коннекторов в единый центр аналитики вместо десятка таблиц
- Сложные Google-таблицы и их связки — когда нужна логика и расчёт, а не только визуализация
- Интеграции ИИ и автоматизация — подключение нейросетей к данным, офисным, операционным и производственным процессам

### Коннекторы (20+)

1С, Битрикс24, Тильда, 1С-Битрикс, МойСклад, Яндекс Кит, Google Таблицы, Avito, 2GIS, Wildberries, Яндекс Маркет, Ozon, Lamoda, Яндекс Метрика, Яндекс Директ, HeadHunter, amoCRM, RetailCRM, MPstats, Yclients, Roistat, произвольный API или MCP.

### Модули и возможности

- **Продажи:** лиды, заказы, воронка, эффективность менеджеров, план-факт, опт/розница/e-com, география
- **Финансы:** выручка, заказы, прибыль по направлениям бизнеса, средний чек, себестоимость, P&L, структура расходов, рентабельность
- **Склад:** складские запасы, оборачиваемость, глубина запасов, товары на складах и в доставке, география
- **Маркетинг:** затраты, эффективность по каналам, воронка, бюджетирование
- **HR и кадры:** текучесть кадров, вовлечённость, удовлетворённость сотрудников
- **Стратегия:** свод показателей в единую платформу по направлениям бизнеса, каналам продаж, каналам рекламы, географии
- **Производство:** эффективность оборудования и процессов, производительность, качество
- **Внедрение ИИ:** анализ полученных данных, преобразование и обработка данных, сокращение трудозатрат исполнителей

### Нейроаналитик (готовый модуль)

Инструмент, который анализирует чарты на дашборде, формирует выводы на основе данных и позволяет задавать уточняющие вопросы. В качестве контекста используются данные отдельных чартов и всего дашборда. Тестировать: https://koncentrat.app/demo

- **Коробочная версия** — закрытый контур, внутренняя инфраструктура компании клиента

### Технологические партнёры

Wildberries API, Yandex DataLens (аккредитованная галерея), Яндекс Cloud, Ozon for developers.

## Направление 2. Готовое SaaS-решение для маркетплейсов

Концентрат — SaaS-сервис бизнес-аналитики для продавцов на российских маркетплейсах.
Инструмент визуализации ключевых показателей управленческого учета и сквозной аналитики в формате единого интерактивного дашборда.
Автоматически подключается к Wildberries, Ozon, Яндекс Маркету и Lamoda через официальные API
и визуализирует ключевые показатели в едином интерактивном дашборде на платформе Yandex DataLens.

Сервис создан практикующими селлерами для селлеров — без перегруженности лишними метриками,
только те данные, которые реально влияют на прибыль.

### Интеграции / Поддерживаемые маркетплейсы (SaaS-тариф)

- Wildberries (WB)
- Ozon
- Яндекс Маркет (Yandex Market)
- Lamoda

Подключение к каждому маркетплейсу — через официальный API в режиме «только чтение».
Данные обновляются ежедневно в автоматическом режиме.

### Базовые модули дашборда

**Wildberries (WB):** заказы, выкупы, соинвест / СПП, средний чек, топ-10 товаров; расходы на рекламу, заказы с рекламы, ДРР, рекламные расходы на 1 заказ; конверсии в корзину и в заказ, возвраты; прибыль, сумма к перечислению, структура расходов, поартикульный P&L; остатки на складах, стоимость хранения; план-факт по заказам/выкупам/сумме к перечислению/прибыли; тепловая карта продаж по регионам, распределение по федеральным округам; детализация заказов и продаж.

**Ozon:** заказы, выкупы, средний чек, топ-10 товаров, % выкупа; расходы на рекламу, структура рекламных расходов, ДРР, выручка с 1₽ рекламы, воронка по рекламным кампаниям; конверсии в карточку/корзину/заказ; прибыль, сумма к перечислению, структура расходов, поартикульный P&L; остатки и стоимость хранения; план-факт по заказам/выкупам/прибыли; тепловая карта по сумме заказов; детализация заказов и продаж.

## Партнёрская программа (koncentrat.app/partners)

Программа для агентств и компаний, у которых уже есть лояльные клиенты — предложить им готовую аналитику без разработки и затрат со своей стороны, укрепляя собственную экспертность и лояльность клиента.

### Модель — «трёхсторонний win-win»

- **Клиент** получает нужный продукт сразу, не откладывая аналитику на потом
- **Партнёр** получает укреплённую лояльность клиента, ничего не разрабатывая и не поддерживая своими силами
- **Koncentrat** получает проект и нового клиента, но заходит только через рекомендацию партнёра, не в обход него

### Кому подходит

- **E-commerce агентства** (реклама, сайты, SMM, контекстная реклама) — закрывают запрос клиентов на данные и результаты в цифрах
- **IT-интеграторы и внедренцы** (CRM, 1С, корпоративные системы, nocode/low-code) — дашборд логично встраивается поверх уже настроенных источников данных; зоны ответственности обсуждаются отдельно на брифе
- **Бухгалтерский, финансовый и консалтинговый аутсорс** — аналитика как естественное продолжение работы с цифрами клиента

### Что партнёр даёт клиенту

- Сбор данных из любых источников клиента — 1С, CRM, МойСклад, Битрикс24, маркетплейсы, Google-таблицы
- Единая картина вместо десятка разрозненных таблиц и Excel-файлов
- Наглядные дашборды, которые обновляются автоматически

### Как это работает

1. Партнёр знакомит с клиентом (рекомендация, представление, короткий разговор)
2. Koncentrat реализует проект — партнёр не разрабатывает, не настраивает и не тратит время команды
3. Клиент получает рабочее решение; по вопросам в первую очередь обращается к партнёру (первая линия), Koncentrat — вторая линия

### Вознаграждение

Помимо укреплённой лояльности клиента партнёрство предполагает материальную благодарность — формат и сумма обсуждаются индивидуально при первом контакте, в зависимости от проекта. От партнёра требуется только представить или познакомить с клиентом — без форм, обязательств и долгих процедур.

## Часто задаваемые вопросы (FAQ)

**Что такое Концентрат?**
Концентрат — сервис аналитики для продавцов на маркетплейсах Wildberries, Ozon, Яндекс Маркет и Lamoda, а также разработчик индивидуальных BI- и ИИ-систем для бизнеса любой отрасли.

**Есть ли бесплатный период?**
Да. 7 дней полного доступа ко всем функциям тарифа Pro — без регистрации и оплаты.

**Сколько времени занимает подключение SaaS-тарифа?**
5–10 минут самостоятельно, без программистов и технических знаний. Точное время зависит от объема данных.

**Данные в безопасности?**
Интеграция только через официальные API маркетплейсов в режиме «только чтение». Пароли от личных кабинетов не запрашиваются и не хранятся. Все данные передаются по SSL-шифрованию. Для индивидуальной разработки доступна коробочная версия с размещением в закрытом контуре клиента.

**Можно ли смотреть несколько маркетплейсов в одном дашборде?**
Да, тариф Pro 4 позволяет подключить от 2 до 4 маркетплейсов и видеть их в едином дашборде.

**Чем Концентрат отличается от MPSTATS и аналогов?**
MPSTATS и подобные сервисы — инструменты для анализа рынка и конкурентов. Концентрат — аналитика собственных продаж, финансов и рекламы продавца. Разные задачи, разные продукты.

**Сколько пользователей можно подключить?**
На тарифах Pro 2, Pro 3 и Pro 4 — без ограничений по количеству пользователей.

**Есть ли API или экспорт данных?**
